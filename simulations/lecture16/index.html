0 · Before Rolle: what do “continuous” and “differentiable” mean?

Idea first: “Continuous: you can draw the graph without lifting your pen. Differentiable: the graph is smooth, with no corner, so one tangent line exists.” The definitions below make these ideas precise.

Definition 1: continuous at a point

f is continuous at x=c if all three hold:
(i) f(c) is defined;
(ii) limx→c f(x) exists, meaning the left-hand limit limx→c⁻ f(x) and the right-hand limit limx→c⁺ f(x) both exist and are equal;
(iii) limx→c f(x) = f(c).
In short: limx→c f(x) = f(c). Continuity fails at c when there is a hole, a jump, or a break.

Definition 2: continuous on an interval

[a,b] (closed interval) includes its endpoints; (a,b) (open interval) does not.
f is continuous on (a,b) if it is continuous at every c in (a,b).
f is continuous on [a,b] if it is continuous on (a,b) and at the endpoints from the inside: limx→a⁺ f(x) = f(a) and limx→b⁻ f(x) = f(b).

Definition 3: differentiable

The derivative of f at c is f′(c) = limh→0 [f(c+h) − f(c)] / h, provided this limit exists as a finite number (the limits from h→0⁻ and h→0⁺ must be equal). Then f is differentiable at c.
f is differentiable on (a,b) if f′(c) exists for every c in (a,b).
Geometric meaning: the graph has one non-vertical tangent line at c, with slope f′(c). A corner, a cusp, a vertical tangent, or a jump means the derivative does not exist.
Key relationship: differentiable at c ⇒ continuous at c. The reverse is false: |x| is continuous at 0 but not differentiable there. Rolle’s Theorem asks for differentiability only on the open interval (a,b), because a derivative at an endpoint would need values of f outside [a,b].

Every differentiable point lies inside the continuous region. The ring between the two ovals is “continuous but not differentiable”.

0b · The Intermediate Value Theorem (IVT)

“At age 5 you were 1.2 m tall, at age 15 you were 1.7 m. At some age you were exactly 1.5 m, because growth has no jumps.”
Intermediate Value Theorem. If f is continuous on [a,b] and N is any number between f(a) and f(b), then there is at least one c in [a,b] with f(c) = N.
Geometry: a continuous graph from the height f(a) to the height f(b) must cross every horizontal line y = N in between. It cannot skip a height without lifting the pen.

Careful: the theorem says such a c exists. It does not say where c is, or that c is the only one. Continuity on [a,b] (Definition 2) is essential: a jump can skip a height.

Simulation: slide N between f(a) and f(b)

f: N

The jump function is f(x)=x for x<1.5 and f(x)=x+2 for x≥1.5. It is not continuous at 1.5, and the heights between 1.5 and 3.5 are skipped, so the theorem does not apply.

Worked examples

① Show x³ + x − 1 = 0 has a solution in [0,1]. f is continuous (a polynomial), f(0) = −1 < 0 and f(1) = 1 > 0. Since 0 is between f(0) and f(1), IVT gives c in (0,1) with f(c)=0.
② Does x⁵ − 3x + 1 = 0 have a root in [0,1]? f(0)=1 and f(1)=−1, so yes.
③ Existence of √2: f(x)=x²−2 on [1,2] has f(1)=−1 and f(2)=2, so some c in (1,2) satisfies c²=2.

Where the IVT is used

Root finding: if f changes sign on [a,b], a root is trapped inside. Halving the interval again and again (the bisection method) is how calculators and computers solve equations.
Existence proofs: it shows a solution exists before you try to find it, for example in the root-counting example for Rolle’s Theorem below.
Real life: temperature, speed and height change continuously, so they pass through every value in between.

1 · Rolle’s Theorem

Teaching order: Rolle first, then MVT. This is the order in Thomas’ Calculus too. Rolle is the simple special case (flat secant), and the proof of the MVT uses Rolle. If you taught MVT first, you could not prove it from simpler facts.
“A ball thrown up leaves your hand at height 2 m and lands at height 2 m. At the top it is not moving up or down.”
Rolle’s Theorem. Suppose ① f is continuous on [a,b], ② f is differentiable on (a,b), and ③ f(a)=f(b) (definitions in Section 0). Then there is at least one c in (a,b) with f′(c)=0.

Geometry: a curve starting and ending at the same height must have a flat tangent somewhere in between.

Animation: the ball (choose a motion)

Motion: speed time

Left: the ball (arrow = velocity). Right: its height graph with the tangent line. In every motion the ball starts and ends at 2 m, so Rolle guarantees a moment with velocity 0, i.e. a flat tangent. It is a maximum when the ball turns from rising to falling, a minimum when it turns from falling to rising. The third motion has two such moments: Rolle promises at least one, not exactly one.

Simulation: test the hypotheses

Choose:

Example: f(x)=x²−4x+3 on [1,3]. f(1)=f(3)=0 and f′(x)=2x−4=0 ⇒ c=2.
Counterexamples (each breaks exactly one check, and then there is no flat tangent):
• f(x)=|x| on [−1,1]: ① holds and ③ holds (f(−1)=1=f(1)), but ② fails at x=0: left slope −1, right slope +1, so f′(0) does not exist. The graph has a corner at its lowest point, not a flat tangent.
• f(x)=x for 0≤x<1 and f(1)=0, on [0,1]: ③ holds (f(0)=f(1)=0) and ② holds inside, but ① fails at x=1: the limit from the left is 1, while f(1)=0.
• f(x)=x on [0,1]: ① and ② hold, but ③ fails (f(0)=0 ≠ 1=f(1)), and indeed f′(x)=1 is never 0.
So all three checks are needed.

Where Rolle’s Theorem is used

① Counting roots. Show x³ + x − 1 = 0 has exactly one real root. f(0)=−1 and f(1)=1, so a root exists between 0 and 1 (Intermediate Value Theorem, Section 0b). Suppose there were two roots r₁<r₂. Then f(r₁)=f(r₂)=0, so Rolle gives a c with f′(c)=3c²+1=0. But 3c²+1 ≥ 1 > 0. Contradiction, so only one root.
② Proving the MVT. Subtract the secant line from f. The new function is 0 at both ends, so Rolle applies (see MVT section).
③ Real-life meaning: any motion that returns to its starting position (a thrown ball, a swing, a piston) must have an instant of zero velocity. Rolle is the base for finding maxima and minima: flat tangents are where they occur.

2 · Mean Value Theorem

“120 km in 1 hour means the average speed was 120. At some instant the speedometer read exactly 120.”
MVT. If f is continuous on [a,b] and differentiable on (a,b), there is c in (a,b) with
f′(c) = (f(b) − f(a)) / (b − a).

Geometry: some tangent is parallel to the secant. Rolle is the case where the secant is flat.

The picture (example f(x) = x² on [1, 3])

The equation, read from the picture:
f′(c) = [ f(b) − f(a) ] / ( b − a )   (slope of the tangent at c = slope of the secant from A to B)
Here: f′(c) = 2c and [ f(b) − f(a) ] / ( b − a ) = (9 − 1) / (3 − 1) = 8/2 = 4, so 2c = 4 and c = 2, which lies in (1, 3) ✓.
Equivalent form: f(b) − f(a) = f′(c)(b − a): the total change equals (a tangent slope) × (the width).
f: a b

Example: f(x)=x² on [1,3]: secant slope (9−1)/2=4; f′(c)=2c=4 ⇒ c=2.

Corollaries (the bridge to antiderivatives)

① If f′(x)=0 on an interval, then f is constant there.
② If f′(x)=g′(x) on an interval, then f(x)=g(x)+C. (Apply ① to f−g.)

Check question: f(0)=0, f(2)=6. Must f′ reach 3 somewhere? Yes, by MVT.

Why MVT follows from Rolle

Let m = (f(b)−f(a))/(b−a) and g(x) = f(x) − [f(a) + m(x−a)] (the curve minus the secant line). Then g(a)=g(b)=0, and g is continuous and differentiable like f. Rolle gives c with g′(c)=0, i.e. f′(c) − m = 0, so f′(c)=m.

Where the MVT is used

① Speed cameras. A car passes camera A at 10:00 and camera B, 100 km away, at 10:50. Average speed = 100/(5/6) = 120 km/h. By MVT the speedometer read exactly 120 at some instant, so the car broke a 100 km/h limit even if no camera saw it.
② Increasing/decreasing test. If f′>0 on an interval then f is increasing there (apply MVT to any two points). This is how you find where a graph rises and falls.
③ Inequalities and error bounds. |sin b − sin a| = |cos c||b−a| ≤ |b−a|. In general, if |f′|≤K then |f(b)−f(a)|≤K|b−a|.
④ Antiderivatives. f′=0 ⇒ f is constant, which gives the “+C”.
⑤ Later topics: it is the key step in proving the Fundamental Theorem of Calculus, Taylor’s theorem with remainder, and L’Hôpital’s rule.

2b · Proof techniques: reduction and contradiction

Two proof ideas appear again and again in this chapter. Both are worth naming for students. (If you meant a different “reduction proof”, tell me and I will adjust this section.)

A · Reduction: turn a new problem into one you already solved

“I don’t know how to prove the MVT directly. But I do know Rolle. Can I reduce the MVT to Rolle?”
Proof of the MVT by reduction to Rolle. Let m = [f(b) − f(a)]/(b − a) and define the new function
g(x) = f(x) − [ f(a) + m(x − a) ] (the curve minus the secant line).
① g is continuous on [a,b] and differentiable on (a,b), because f is and the line is.
② g(a) = f(a) − f(a) = 0 and g(b) = f(b) − f(a) − m(b − a) = 0. So g(a) = g(b).
③ Rolle applies to g: there is c in (a,b) with g′(c) = 0.
④ g′(x) = f′(x) − m, so f′(c) − m = 0, i.e. f′(c) = m. ∎

Simulation: watch the reduction happen

f: a b

Left: f with its secant. Right: g = f − (secant). The secant becomes the flat line y = 0, and the end heights match, so Rolle applies. The green dot on the right (flat tangent of g) is the same c as the green point on the left (tangent parallel to the secant).

The chain of results (each reduces to the one before)

Rolle ⇒ MVT ⇒ (f′ = 0 ⇒ f is constant) ⇒ (f′ = g′ ⇒ f = g + C) ⇒ the “+C” of antiderivatives.
Proof of “f′=0 ⇒ f constant”: take any x₁ < x₂ in the interval. MVT gives c with f(x₂) − f(x₁) = f′(c)(x₂ − x₁) = 0·(x₂ − x₁) = 0. So f(x₂) = f(x₁) for all pairs. ∎

B · Contradiction (reductio ad absurdum)

Three steps:
1. Assume the opposite of what you want to prove.
2. Argue correctly until you reach something impossible (a contradiction).
3. Conclude the assumption was false, so the original statement is true.

Example ①: x³ + x − 1 = 0 has exactly one real root.
Existence: f(0) = −1 and f(1) = 1, so the IVT gives a root in (0,1).
Uniqueness: assume there are two roots r₁ < r₂. Then f(r₁) = f(r₂) = 0, so Rolle gives c in (r₁, r₂) with f′(c) = 3c² + 1 = 0. But 3c² + 1 ≥ 1 > 0 for every c. Contradiction, so there cannot be two roots. ∎

Example ②: x³ − 3x + k = 0 has at most one root in [−1, 1], for every constant k.
Assume two roots a < b in [−1,1]. Rolle gives c in (a,b) with f′(c) = 3c² − 3 = 0, so c = ±1. But (a,b) lies inside [−1,1], so c is strictly between −1 and 1. Contradiction. ∎

Example ③: no differentiable f has f(0) = 0, f(2) = 6 and f′(x) < 2 for all x.
Assume such an f exists. MVT gives c with f′(c) = (6 − 0)/(2 − 0) = 3. But f′(c) < 2. Contradiction. ∎

Pattern in Examples ① and ②: “Two roots” ⇒ (Rolle) a flat tangent between them ⇒ but f′ is never 0 there ⇒ contradiction. Whenever f′ has no zero on an interval, f has at most one root there.

3 · Linearization and Differentials

3a · Geometric idea (10 min)

Zoom in on a smooth curve at x=c and it looks like its tangent line.

3b · Algebraic idea: you don’t need f(x)

All you know: the point f(c) and slope f′(c). The tangent line there is
L(x) = f(c) + f′(c)(x − c),  and f(x) ≈ L(x) near c.
f: position zoom

Drag zoom right: the curve and the tangent become indistinguishable. That is why linearization works.

Worked examples (5 min)

① √4.1: f(4)=2, f′(4)=1/4 ⇒ L(4.1)=2+0.1/4=2.025 (true 2.02485).
② (2.01)³: f(2)=8, f′(2)=12 ⇒ L(2.01)=8+12(0.01)=8.12 (true 8.120601).
③ Standard ones at c=0: sin x≈x, (1+x)ᵏ≈1+kx, eˣ≈1+x.

3c · Differentials, step by step (10–12 min)

Step 1: the true change. Let y = f(x). If x changes by a small amount Δx (from x to x + Δx), then y changes by
Δy = f(x + Δx) − f(x).
Example: f(x) = x³, x = 2, Δx = 0.01: Δy = (2.01)³ − 2³.
Step 2: the problem. Computing Δy needs f at the new point, which can be hard by hand (try 2.01³). We want a quick estimate that uses only information at x.
Step 3: use the tangent line. Near x, the curve is almost the same as its tangent. Moving a horizontal distance Δx along the tangent line raises it by (slope) × (run) = f′(x) · Δx. That rise is easy to compute.
Step 4: define the differentials.
dx = Δx (the differential of x: just the chosen small step, any number)
dy = f′(x) dx (the differential of y: the rise along the tangent)
Difference: Δy is the rise along the curve, dy is the rise along the tangent.
This is why dy/dx = f′(x) can be read as a genuine ratio of two small quantities.
Step 5: compare dy and Δy. Use the simulation: drag dx and watch the orange piece (dy) and the red piece (the error Δy − dy).
f(x)=x³ at x=2, dx
Step 6: use dy to estimate a new value.
Idea in words: new value = old value + change. We don’t know the true change Δy, so we use its easy estimate dy:
f(x + dx) ≈ f(x) + dy,   where dy = f′(x) · dx.

Example: estimate (2.01)³ without a calculator.
① Choose f(x) = x³ and a nearby point that is easy: x = 2. Old value: f(2) = 8.
② Slope there: f′(x) = 3x², so f′(2) = 12.
③ Step size: dx = 2.01 − 2 = 0.01.
④ Estimated change: dy = 12 × 0.01 = 0.12.
⑤ New value ≈ 8 + 0.12 = 8.12.
Picture: you stand at height 8 on a hill whose slope is 12. Take a tiny step 0.01 to the right and you rise about 12 × 0.01 = 0.12. (This is the same as the linearization L(x).)
Step 7: how wrong is the estimate?
Error = true change − estimated change = Δy − dy.
For (2.01)³: true value = 8.120601, estimate = 8.12, so the error is 8.120601 − 8.12 = 0.000601. Very small.
How is the true change Δy found? Directly, by evaluating f at both points: Δy = f(2 + dx) − f(2). For dx = 0.1: 2.1³ − 2³ = 9.261 − 8 = 1.261. (We do this only to check the estimate; in practice you skip it.)

What the table shows:
• A big step (dx = 1) gives a poor estimate: 12 instead of 19.
• A small step gives an excellent estimate.

Why: the curve bends away from its tangent line, and the gap grows with the square of the distance from the touching point.
Algebra check (optional): Δy = (2 + dx)³ − 8 = 12·dx + 6·dx² + dx³. The first term, 12·dx, is exactly dy. The rest, 6·dx² + dx³, is the error, and it contains dx², which explains the pattern.
Takeaway: always use a small dx.
Step 8: error in measurement (the main application). If x is measured with error dx, then y = f(x) has
absolute error ≈ dy = f′(x) dx, relative error ≈ dy / y, percentage error = (dy / y) × 100%.
Example (sphere): radius r = 10 cm measured with error dr = 0.1 cm. V = (4/3)πr³, so dV = 4πr² dr = 4π(100)(0.1) ≈ 125.7 cm³. V = (4/3)π(1000) ≈ 4188.8 cm³, so dV/V = 3 dr/r = 0.03, a 3% volume error from a 1% radius error.
Example (square): side x = 10 cm, dx = 0.2: A = x², dA = 2x dx = 2(10)(0.2) = 4 cm², so dA/A = 4/100 = 4%. A 2% error in the side (0.2/10) gives about a 4% error in the area.
Common mistakes: (1) writing dy = Δy (they are equal only for a straight line); (2) using a large dx (the tangent drifts away from the curve); (3) forgetting that dx is the input change and dy the predicted output change; (4) mixing units of dx and f′(x).

Differential rules (just the derivative rules with dx attached): d(c) = 0, d(xⁿ) = n xⁿ⁻¹ dx, d(sin x) = cos x dx, d(eˣ) = eˣ dx, d(u + v) = du + dv, d(uv) = u dv + v du.

Check question: the area of a circle is A = πr². If r = 5 changes to 5.1, estimate the change in area with a differential. (dA = 2πr dr = 2π(5)(0.1) = π ≈ 3.142. True change: π(5.1² − 5²) = 1.01π ≈ 3.173, so the estimate is off by only about 0.03.)

“Derivative: given the function, find the slope. Antiderivative: given the slope, find the function.”
